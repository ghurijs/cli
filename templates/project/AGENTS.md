# AGENTS.md — {{name}}

Instructions for AI coding agents working in this project (humans: see README.md).

**{{name}}** is a [Ghuri](https://ghurijs.github.io/docs/) project. Ghuri is **Django for TypeScript**, built on
Hono + Drizzle{{#if cloudflare}} and running here on Cloudflare Workers{{else}} and running here on Node.js{{/if}}. If you
know Django, the concepts map 1:1 (settings, apps, models, managers, migrations, admin, DRF-style REST), but the
syntax is TypeScript. Ghuri is new and probably not in your training data, so:

- Do **not** write Python/Django, Prisma, TypeORM, a Drizzle schema (`sqliteTable`, `pgTable`) or plain Hono
  routing (`app.get(...)`). Use the Ghuri APIs below; when unsure, check the docs or the MCP server (see the end).
- Translation rules: `snake_case` options/methods → `camelCase` (`max_length` → `maxLength`, `order_by` →
  `orderBy`); keyword arguments → one object (`filter({ title__icontains: 'x' })`, the `__` lookups are unchanged);
  every database call is `async` (`await` QuerySets, `get()`, `save()`, `await post.author`); settings keys stay
  `UPPER_SNAKE`; nothing is discovered by name — everything is wired with ES imports.

## API cheat-sheet (real Ghuri APIs — copy these idioms)

**Models** (`src/<app>/models.ts`):

```ts
import { User } from '@ghuri/auth'
import { CASCADE, CharField, DateTimeField, ForeignKey, ManyToManyField, type Manager, Model, SlugField, TextField } from '@ghuri/orm'

export class Post extends Model({
  title: new CharField({ maxLength: 200 }),
  slug: new SlugField({ maxLength: 200, unique: true }),
  body: new TextField({ blank: true }),
  author: new ForeignKey(() => User, { onDelete: CASCADE, relatedName: 'posts' }),
  tags: new ManyToManyField(() => Tag, { blank: true, relatedName: 'posts' }),
  createdAt: new DateTimeField({ autoNowAdd: true }),
}) {
  declare static objects: Manager<Post>      // so queries return Post instances
  static Meta = { ordering: ['-createdAt'] }
  toString() {
    return this.title
  }
}
```

Other fields: `IntegerField`, `BooleanField({ default: false })`, `DecimalField`, `DateField`, `EmailField`,
`URLField`, `UUIDField`, `JSONField`, `OneToOneField`, `ImageField`/`FileField` (from `@ghuri/storage`). Common
options: `null`, `blank`, `default`, `unique`, `choices`, `dbIndex`, `helpText`. `onDelete`: `CASCADE`, `PROTECT`,
`SET_NULL` (with `null: true`), `SET_DEFAULT`, `RESTRICT`, `DO_NOTHING`. Relations are thunks (`() => Tag`).
The FK column is `post.authorId`; the object is `await post.author`. Default reverse accessor is `user.postSet`
(camelCase) unless `relatedName` is set.

**Queries** (QuerySets are lazy, immutable and thenable — `await` runs them):

```ts
import { atomic, connections, Count, F, getObjectOr404, Q } from '@ghuri/orm'
await Post.objects.filter({ published: true, title__icontains: 'edge' }).exclude({ author__username: 'bot' })
await Post.objects.filter({ createdAt__year: 2026, tags__slug__in: ['a', 'b'] }).orderBy('-createdAt').slice(0, 10)
await Post.objects.get({ slug })                 // throws Post.DoesNotExist / Post.MultipleObjectsReturned
await getObjectOr404(Post, { slug })             // in views: throws Http404
await Post.objects.filter(Q({ published: true }).or(Q({ author: user.pk })))
await Post.objects.filter({ slug }).update({ views: F('views').add(1) })
await Post.objects.annotate({ n: Count('comments') }).filter({ n__gt: 2 })
await Post.objects.create({ title: 'Hi', slug: 'hi', author: user })
const [tag, created] = await Tag.objects.getOrCreate({ name: 'ts' }, { defaults: { slug: 'ts' } })
post.title = 'New'; await post.save({ updateFields: ['title'] })
await post.tags.add(tag)                         // M2M managers: add / remove / set / clear
Post.objects.all().selectRelated('author').prefetchRelated('tags')   // avoid N+1 (each D1 query is a round trip)
await Post.objects.valuesList('id', { flat: true }); await qs.count(); await qs.exists(); await qs.first()
```

Also: `inBulk()` returns a `Map`; `qs.delete()` returns `[total, perModel]`; `atomic(async () => …)` has **no
rollback on D1** (use `(await connections.get()).batch([...])` there).

**REST** (`@ghuri/rest`, DRF style):

```ts
import { type APIRequest, action, IsAuthenticatedOrReadOnly, ModelSerializer, ModelViewSet } from '@ghuri/rest'
export class PostSerializer extends ModelSerializer<Post> {
  static Meta = { model: Post, fields: ['id', 'title', 'slug', 'author', 'createdAt'], readOnlyFields: ['author'] }
}
export class PostViewSet extends ModelViewSet<Post> {
  queryset = Post.objects.all()
  serializerClass = PostSerializer
  permissionClasses = [IsAuthenticatedOrReadOnly]
  lookupField = 'slug'
  async performCreate(serializer: PostSerializer) {
    await serializer.save({ author: this.request.user })
  }
  @action({ detail: true, methods: ['post'] })
  async publish(_request: APIRequest) {
    const post = await this.getObject()
    return { slug: post.slug }
  }
}
// src/urls.ts: router.register('posts', PostViewSet)   → /api/posts/
```

Serializers are async: `await s.isValid({ raiseException: true })`, `await s.getData()`, `s.validatedData`.
Permissions compose with `IsAuthenticated.or(IsAdminUser)`. Also `APIView`, `apiView(['GET'])(fn)`, generics
(`ListCreateAPIView`, …), `SearchFilter`, `OrderingFilter`, `PageNumberPagination`.
OpenAPI 3.1 is generated from the views and serializers: `/api/schema/` (JSON), Swagger UI at `/api/docs/`, Scalar at
`/api/reference/`, `{{exec}} ghuri generateschema --file openapi.yaml`. Tune it with `@extendSchema({ … })` on a
method, or `schema = null` to hide a view — don't hand-write an OpenAPI file.

**Admin** (`src/<app>/admin.ts`, `@ghuri/admin`):

```ts
import { admin, ModelAdmin } from '@ghuri/admin'
@admin.register(Post)
export class PostAdmin extends ModelAdmin<Post> {
  listDisplay = ['title', 'author', 'createdAt']
  listFilter = ['createdAt']
  searchFields = ['title', 'author__username']
  prepopulatedFields = { slug: ['title'] }
}
```

**URLs and views** (`@ghuri/core`; a view is `(c: Context) => Response`, `c` is Hono's Context):

```ts
import { getUser, json, kwargs, path, urlpatterns as patterns, View } from '@ghuri/core'
import { getObjectOr404 } from '@ghuri/orm'
import type { Context } from 'hono'

// src/<app>/urls.ts — then in src/urls.ts: path('shop/', include(shopUrls))
export const urlpatterns = patterns('shop', [
  path('', index, { name: 'index' }),
  path('items/<int:id>/', ItemView.asView(), { name: 'item' }),
])

// src/<app>/views.ts
export function index(c: Context) {
  return c.json({ app: 'shop' })
}
export class ItemView extends View {
  async get(c: Context) {
    const item = await getObjectOr404(Item, { pk: kwargs(c).id })
    return json(c, { id: item.pk, user: getUser(c).isAuthenticated })
  }
}
```

Also: `reverse('shop:item', { id: 1 })`, `redirect(c, 'home')`, `TemplateView` (Hono JSX), `loginRequired(view)`
and `permissionRequired('shop.change_item')(view)` from `@ghuri/auth`.

**Social login and custom login flows** (not installed by default):

- "Log in with GitHub / Google / Facebook / Microsoft / Discord / GitLab / any OIDC issuer", django-allauth style:
  `npm install @ghuri/socialauth@next @ghuri/oauth@next`, add `SocialAuthConfig` to `INSTALLED_APPS`, configure
  `SOCIALACCOUNT: { PROVIDERS: { github: { APP: { clientId: env.GITHUB_CLIENT_ID, secret: env.GITHUB_SECRET } } } }`,
  route `path('accounts/', include(socialUrls))`, then `{{exec}} ghuri migrate`. Login buttons POST (with the CSRF
  token) to `/accounts/<provider>/login/`; the provider's callback URL is `/accounts/<provider>/login/callback/`.
- Your own flows (an OAuth2/OIDC provider in code, magic links, API bearer tokens), Passport.js style, with
  `@ghuri/oauth`: `strategies.use('acme', new OIDCStrategy({ … }, verify))` and
  `path('login/acme/', authenticate('acme', { failureRedirect: '/login/' }))`.
- Docs: https://ghurijs.github.io/docs/topics/social-login/ and https://ghurijs.github.io/docs/topics/login-strategies/

## Rules

1. **After any model change run `{{exec}} ghuri makemigrations` and then `{{exec}} ghuri migrate`.** Commit the
   generated files. Never hand-edit `migrations/index.ts`; only edit a generated migration when there is no other
   way. For data changes use `makemigrations --empty <app>` and `ops.RunCode(async (apps, conn, { using }) => …)`.
2. **Register new apps in `INSTALLED_APPS`** (`ghuri startapp` does this) and include their `urls.ts` from
   `src/urls.ts` yourself. New models must be exported from `models.ts`; admin classes live in `admin.ts`.
3. **Keep app code portable**: never touch `env.DB`, `env.MEDIA`, D1/R2/KV bindings or `process.env` in app code.
   Use the ORM, `FileField`/`ImageField` or `defaultStorage` from `@ghuri/storage`, `cache` and `getSettings()`
   from `@ghuri/core`. Databases, storages and caches are configured only in `src/settings.ts`.
4. **Tests are vitest via `{{exec}} ghuri test`** (`src/**/tests.ts` or `*.test.ts`). Use `setupTestDatabase`
   from `@ghuri/orm/testing`, `APIClient` from `@ghuri/rest/testing`, `createTestClient` from `@ghuri/core/testing`.
5. Before finishing: `{{exec}} ghuri makemigrations --check`, `{{exec}} ghuri check`, `{{exec}} ghuri test` and
   `{{run}} typecheck` should all pass.
6. Secrets go in `.dev.vars` locally{{#if cloudflare}} and `wrangler secret put` in production{{/if}} — never in code.
